# 눌림목 매수 백테스트 — 사용 설명서

코딩을 몰라도 따라 할 수 있게 적었습니다. 검은 화면(터미널)에 아래 글자를 **그대로 복사해서 붙여넣고 엔터**만 누르면 됩니다.

## 이게 뭔가요?

"실적이 기대에 못 미쳐 주가가 떨어지면 사고, +7~10% 오르면 팔고, -7~10% 떨어지면 더 산다"는 내 규칙을
**지난 5년 동안 실제로 했다면 어땠을지** 컴퓨터로 흉내 내 본 것입니다.

- 종목: ABNB, AMZN, AVGO, ISRG, MA, META, NFLX, V
- 기간: 2021-11-04 ~ 2026-11-03 (매일 가격)
- 결과는 **추천이 아니라 과거 기록 확인용**입니다.

## 결과만 보고 싶으면

- `report.html` → 더블클릭하면 인터넷 창에서 열립니다 (휴대폰에서도 보기 좋게 만듦)
- `결과요약.md` → 메모장으로 열어도 되는 짧은 요약

## 규칙을 바꾸고 싶으면

`backtest.py` 파일을 메모장으로 열고 위쪽의 숫자만 바꾼 뒤 3단계를 다시 하세요.

| 이름 | 지금 값 | 뜻 |
|---|---|---|
| `X_LIST` | `[7, 8, 9, 10]` | 익절·물타기 기준 % |
| `DROP_PCT` | `0.08` | 최근 고점보다 몇 % 떨어지면 매수 신호로 볼지 (0.08 = 8%) |
| `LOOKBACK` | `20` | 고점을 며칠 동안에서 찾을지 |
| `WITHIN_DAYS` | `5` | 고점 후 며칠 안에 떨어져야 '급락'인지 |
| `MAX_ADDS` | `2` | 물타기 최대 횟수 |
| `FEE` | `0.0025` | 수수료 (0.0025 = 0.25%) |

## 꼭 알아둘 점

- **'실적 미스' 자료를 구하지 못했습니다.** 그래서 "최근 20일 고점보다 8% 이상, 5일 안에 떨어짐"을 대신 썼습니다. 실적과 상관없는 하락도 섞여 있습니다.
- 손절 규칙이 없어서 **승률은 높게 나오지만**, 안 팔고 오래 버틴 손실 거래가 숨어 있습니다 (예: NFLX -40%).
- 돈을 3등분해서 쓰므로 대부분의 기간 돈이 현금으로 쉬고 있습니다. 그래서 '그냥 사서 보유'보다 수익률이 낮게 나옵니다.
- 환율, 세금(해외주식 양도세), 체결 미끄러짐은 계산에 넣지 않았습니다.
